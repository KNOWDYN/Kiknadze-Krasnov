# Experimental scope for the PoF V2 package

The V2 submission uses three distinct experimental questions and does not treat them as one ranking problem.

1. **Direct V1 local zero-crossing test.** The main manuscript uses V1 only as a steady mean-field spatial consistency test comparing a directly reconstructed radial-velocity zero with a derivative-based radial diffusive-vorticity-flux zero.
2. **Fit-based all-condition common-zero mining.** A separate common estimator across all eight BCO-DMO conditions identifies H2 as the strongest resolved positive-radius candidate and V3 as a secondary, resolution-limited candidate.
3. **Global KK-versus-Burgers/source identification.** Full-profile model comparison and independent source estimates leave the resolved archive predominantly Burgers-like and do not establish a quantitatively self-consistent positive-q KK state.

The experimental archive is a steady measured mean field. It does not test time-dependent materiality, exact material-circulation conservation, or the exponential selection law; those are analytical results of the exact KK solution.
