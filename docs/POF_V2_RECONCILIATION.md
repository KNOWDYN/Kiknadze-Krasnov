# Physics of Fluids V2 reconciliation

The Physics of Fluids revision **Selective material circulation conservation in the unsteady Kiknadze–Krasnov vortex** uses the selective-conservation formal layer added by `KiknadzeKrasnov/SelectiveConservation.lean`.

The manuscript distinguishes three complementary uses of the BCO-DMO laboratory archive: (1) the direct V1 local zero-crossing consistency test shown in the main article, (2) fit-based all-condition common-zero mining, for which H2 is the strongest resolved positive-radius candidate and V3 is secondary/resolution-limited, and (3) global KK-versus-Burgers/source-parameter identification, which remains predominantly Burgers-like and does not identify a self-consistent positive source parameter.

This note records the interpretation used for the V2 submission package. It does not alter the mathematical theorem statements or the trust boundary of the Lean development.
