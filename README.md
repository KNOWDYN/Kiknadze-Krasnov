# Kiknadze–Krasnov Lean Formalisation

Machine-checked Lean 4 + Mathlib formalisation of the mathematical results in *Exact Material Circulation Surface in an Unsteady Viscous Vortex*.

The project is developed in eight audited passes. Source-to-formal-specification artefacts are kept under `docs/` and subsequent Lean code must remain traceable to that frozen specification.
